# Changelog

All notable changes to TechPlatform will be documented in this file.

This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-22

### Added

- Initial release of TechPlatform.
- Microservices architecture using Java 25 and Spring Boot 4.1.1.
- Angular 22 frontend with authentication and protected routes.
- Product, order, and user management.
- JWT authentication and role-based authorization.
- Centralized API routing through Spring Cloud Gateway.
- REST communication between microservices using WebClient.
- Apache Kafka integration for asynchronous messaging.
- Microsoft SQL Server 2022 and MongoDB persistence.
- Stock validation, updates, and restoration on order cancellation.
- Interactive API documentation with Swagger/OpenAPI.
- Docker Compose configuration for eight services.
- Nginx configuration for the Angular frontend.
- GitHub Actions continuous integration workflows.
- SQL Server database initialization script.
- Technical documentation in `README.md`.
